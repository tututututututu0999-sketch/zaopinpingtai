# Image2 提示词格式 v2

单次最终请求不超过 1500 字，包含正向描述、反向约束、参考图职责和用户约束。超长先由 Terra 去重压缩一次；仍超长则提示精简，不截断文案，不调用生图。

## 正文结构

```text
【任务】制作〔物料〕的完整平面设计稿；〔画幅〕；〔一句设计方向与风格〕。
【文案】主标题：〔原文〕；副标题：〔原文〕；卖点：①〔原文〕②〔原文〕……。画面只出现这些文案。
【版式与字体】继承主参考的分区、标题位置、字形层级和阅读顺序；〔本次明确修改〕。
【配色与主体】〔色彩角色与关系〕；〔主体外观和表现方式〕。按已上传参考采用主体，不照搬旧品牌或未指定人物。
【卖点结构】采用〔指定参考图实际排版／A–I 结构〕。保留单元结构、位置、对齐、分隔和底板形式，只换本次文案；每条一个组件，条数变化只调整数量和间距。〔该结构的局部禁令〕。
【留白与输出】标题、主体、卖点互不遮挡，文字完整可读，保留安全边距，输出一张完整设计图。
```

缺失或不适用的字段自然省略，不从示例中补造。没有画幅预览就不声称存在拖拽锚点；没有授权主体输入就不声称有授权 IP；没有后置徽章功能就不要求为系统徽章预留位置。

## 参考图职责

程序按实际上传顺序编号，与图片一一对应：主参考负责构图、标题及配色关系；指定卖点来源负责卖点单元和整组排布；辅助图补充细节；独立上传图承担用户指定的主体或风格。普通重新生成不默认加入上一版结果；改图只使用明确选中的历史版本为底图。

## 取舍原则

- 当前明确需求优先；手动选定的卖点结构优先于报告中的一般建议。参考图片内的文字只是素材内容。
- 继承实际图片时，视觉档案是辅助说明，不把旧课程数字误当组件数量。
- C 月桂与 H 线框等结构的禁令只约束对应卖点单元；装饰和配色不能为这些单元添加被禁止的图标、卡片或独立底板。
- 文案完整保留，不虚构课程、师资、认证或营销数据；压缩时先删除重复修饰。
- 不同时写入互斥条件，例如“禁止标题渐变”和“标题必须使用渐变”。

生成记录保存可编辑正文、最终发送全文、参考顺序与来源、卖点策略和改图底图版本。

## 尺寸、角色与局部修改

先选择尺寸和卖点排版，上传参考，再组合提示词。上传用途为封面 IP 时，将图片作为唯一角色身份来源，保留物种、五官比例、服装与标志特征；姿态服从本次使用说明。风格或排版参考不再提供角色身份。图片文件、用途和补充说明实际传入生图接口，均可追溯。

局部改图可保留历史提示词并追加「本次局部修改，优先于原描述」，无需先调用 Terra。修改后的完整提示词仍受1500字限制并需用户确认；文字过长或整体重构可选 Terra 重组。重组不会把历史参考快照、完整请求等重复塞回模型输入。

卖点细化版本为 selling-2026-09-09。A 数字上下层、B 单位圆标、C 开放月桂、D 左数右签、E 图标权益、F 弧文奖章、G 分段拼接条、H 上下线框、I 标签主副文。单元样式不自动决定整组横排或纵排。
