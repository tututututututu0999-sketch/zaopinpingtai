# 网站操作流程

## 最短路径

填写需求 → 分析并确认方向 → 选择参考方式 → 选择尺寸与卖点结构 → 组合提示词 → 确认生图 → 下载。

## 1. 填写本次需求

进入「创建设计」，选择文本与识图模型，填写产品、目标用户、主标题、副标题、逐条卖点及特殊要求。课程数字、文字和指定颜色应直接写明；需要特定角色时，稍后上传角色图片。

点击「分析设计需求」，核对设计方向与风格关键词。有偏差时填写补充，点击「修正设计方向」，再确认。风格词不是固定色板。

## 2. 选择一种参考方式

| 方式 | 操作 | 适合情况 |
| --- | --- | --- |
| 套系库检索 | 确认方向并检索，选择套系及辅助素材，确认参考 | 复用已审核、已索引的项目 |
| 独立上传参考 | 上传图片，选择整体风格、排版参考或封面 IP，填写必要说明并保存，确认上传参考 | 使用自己的参考图，不检索旧项目 |
| 无参考创作 | 确认方向并直接创作 | 不提供整体参考，由 AI 设计 |

套系分支也可以补充上传参考。特定封面角色应标为「封面 IP」，不要只选「整体风格」；照片默认保留摄影表现。多张图各司其职，不必给每张重复填写同一说明。

切换方式只显示当前分支。本次页面会话内保留各分支设置；修改需求后需要重新确认。不要把刷新浏览器当作继续任务的方式：当前界面尚不保证完整恢复未完成的页面操作。

## 3. 先确定尺寸和设计设置

在组合提示词前选择横版、竖版或方版尺寸。有参考时可选贴近参考、适度发挥、大胆探索，控制未锁定的构图、字体及装饰。

用户最新明确需求优先，其次原始需求，再参考图，最后 AI 建议。明确指定「蓝色调」等颜色时，最终提示词顶部列出用户原文，整体配色服从该要求。有参考且未指定颜色时沿用参考配色；无整体参考时 AI 自主配色，没有固定色板。在补充框中输入的要求需点击补充修正并确认后才参与生图；未提交时会提醒。

卖点可以跟随参考，或明确选择 A–I 分类。选定分类后，即使大胆探索也保留单元结构；对应样图会实际传入生图，但不提供配色或整张封面的比例。卖点内容与组件数量以本次文案为准。

## 4. 组合、核对并生成

点击「组装生图提示词」。界面仅展示实际发送的完整提示词，包含文案、画幅、配色、卖点、参考图职责和反向要求，总长最多 2000 字。点击「复制提示词」可以一次复制全文。

核对主副标题、每条卖点、IP、参考职责及尺寸。此框只读；需要调整时回到需求或设置中修改，再点击「重新组合提示词」，避免只改正文而与附加规则冲突。

点击「确认并生图」。生成需要等待，不要重复提交。失败时查看当前步骤错误并重试，不需要重新上传所有参考。

## 5. 选择结果、修改或下载

生成后在主视觉区查看结果。历史仅展示成功出图的版本，失败原因在当前步骤展示，可重试；旧失败记录不占历史编号。点击历史缩略图切换版本，图片旁唯一的「下载原图」按钮下载当前选中版本。

选择「修改这个版本」后，有两条路径：

- **直接改图**：填写本次要改的内容，可在弹窗「本次专用参考」选择色彩/风格、人物/IP或排版用途，写好说明后上传图片（最多3张，人物/IP最多1张）。点击「确认修改并生成」，实际发送所选底图＋本次意见＋本次专用参考，不叠加旧提示词或自动混入项目参考。沿用底图尺寸，成功后保存为新版本；失败保留底图、修改意见和本次参考，可重试。成功后本次参考清空，下一次按需重新选，不影响项目参考。
- **重组提示词**：适用于整体方向、画幅调整，或需重新使用上传 IP、卖点样图等参考。文本模型结合完整设计上下文和本次意见重组，查看实际提示词后再确认生图。项目中的原参考和历史版本始终保留。

## 6. 延展物料（可选）

先选择满意的封面版本，点击「确认主视觉参考」。填写课程卡、说明卡、手册等模块名称，添加模块并开始设计。每个模块单独确定需求、参考、尺寸和提示词；已确认主视觉自动作为系列参考，模块各自保留生成版本及下载入口。

## 素材库维护（独立流程）

「导入套系」上传项目 ZIP → 「审核队列」确认素材信息与视觉识别 → 后台向量化 → 成功后进入正式检索。仅上传完成不等于已经可检索；索引失败可重试，已发布素材在项目库查看。
