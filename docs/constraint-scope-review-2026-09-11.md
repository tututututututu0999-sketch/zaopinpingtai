# 需求与参考约束审查

## 根因及修复

用户的“圆润描边标题、三条卖点、每条配图标”描述的是最终封面。旧分析把它们写入 hardConstraints，检索、任务确认、逐图识别和生图前检查又共用了同一数组，因此 IP 素材也被要求包含标题与卖点。

约束现在分成参考筛选与最终生成两个范围。只有明确针对参考图/素材筛选、能对应用户原句的要求进入 hardConstraints；其余保留在 generationConstraints / generationNotes，并传给报告及完整生图提示词。采用 `constraintScopeVersion: 2`；读取旧需求时进行兼容解释，不覆盖已保存的原始需求或生成历史。界面展示中文分类及原文来源，不展示 ROUNDED_OUTLINE 等内部 ID。

仅提供身份的 character 图不检查标题/卖点字段。独立上传确认后的快照不在生图时重复识别；套系附加上传图只检查适用的明确参考限制。真实参考排除条件仍然生效，不把未知视觉信息当成满足条件。

“小学”现在作为小学各年级的集合检索；具体年级继续按具体条件检索。空结果说明真实筛选范围，不在无额外限制时统一归因于“硬约束”。

## 无参考创作

`reference_source=none` 与 catalog / upload 并列，由迁移 07 扩展数据库检查约束。此模式没有套系素材和用户上传，报告步骤采用确定性的需求摘要，直接进入生成设置。默认自主设计，可选卖点分类；选分类时仍附带系统分类样图。无图片输入时调用图片生成，有分类样图、历史改图底图或父主视觉时调用图片编辑。

三种模式在页面会话内各自保存草稿，切换不重复上传或调用 AI。修改需求后清空当前分支确认，数据库历史保持不变。页面刷新后的工作恢复不属于这次新增能力。

## 模型

可选目录仅保留 Luna、Terra、qwen-3.8-free。没有检测记录的模型不默认宣称识图成功。通过真实色块图片测试，需正确识别颜色、顺序和形状；正方形也属于矩形，允许该有效答案。Responses / Chat 分别有 25 秒测试机会，避免第一路超时耗尽第二路预算。

## 验证

- 18 项单元测试：旧约束兼容、原文保留、明确参考排除、IP 字段范围、无参考排版、2000 字边界。
- 隔离数据库集成：303 张素材、年级集合、旧任务、独立上传、无参考任务到真实路由的模拟生图与原图下载，未调用付费生图。
- 1440 / 390 像素交互回归：分支互斥与草稿保留、失败重试、无参考全流程、模型选择、下载链接、无横向溢出。
- 类型检查、Lint、生产构建通过。

正式环境复验：原报错需求 c9dc0398-64d8-4cac-879b-77622a3c5673 的检索接口恢复返回套系。2026-09-11 10:25（北京时间）真实图片检测：Luna / Responses 4.306 秒、Terra / Chat 3.356 秒、qwen-3.8-free / Responses 1.218 秒，均通过颜色与图形识别，结果已保存到模型检测表。

## 已知边界

参考筛选来源采用保守的原文范围识别；歧义要求默认作为成图要求保留，不擅自要求每张参考图实现。真正相互矛盾的最终设计要求仍需澄清，模型识图检测通过不保证所有复杂任务均能完成或长期稳定。
